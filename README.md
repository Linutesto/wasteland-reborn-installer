# Wasteland Reborn

Play Fallout 2 on Android with the classic or HD edition, built on the open source Fallout 2 Community Edition engine with the Restoration Project (RPU) and a touch interface. Optional AI NPCs run through Ollama.

**Latest release: v1.4.** Fallout 2 is not included; you need your own copy from Steam, GOG or Epic. This is an unofficial fan project.

The download is about 910 MB total. Keep at least **3 GB free** to download and unpack the art alongside the game files (about 2 GB unpacked).

## Install

### Android only

1. Download and install the classic or HD APK above. Allow your browser or file manager to install apps when Android asks.
2. Copy your Fallout 2 folder to the phone, or copy it as a ZIP, 7z or RAR archive. It must contain `master.dat` and `critter.dat`.
3. Open the app, choose the folder or archive, and let it import the game. In HD, accept or defer the optional art download.

### Windows PC and Android phone

1. Download and run the matching Windows installer. Choose your own Fallout 2 installation when prompted.
2. The setup can install the game on your phone over USB or wireless debugging. You can also do this later from the Start menu.
3. Start the **Wasteland** or **Wasteland HD** app on the phone.

See the [Windows guide](docs/INSTALL-WINDOWS.md), [French guide](docs/INSTALL-WINDOWS.fr.md), and [troubleshooting](docs/TROUBLESHOOTING.md) ([français](docs/TROUBLESHOOTING.fr.md)).

### Linux

Linux installation is available with `linux/install.sh`; see the [Linux guide in English](docs/INSTALL-LINUX.md) or [en français](docs/INSTALL-LINUX.fr.md). Installing on a real phone from Linux has not been tested yet.

### Optional AI NPCs

AI NPCs are optional and use Ollama. Fallout 2 works without AI or an internet connection after installation.

## HD art coverage

The HD packs replace the world floors, walls, scenery and items; talking heads; and inventory, loot, barter, HUD item, skill art, elevators, town pictures and dialogue backgrounds. The Pip-Boy, skilldex, settings (including the touch interface's own look), world-map terrain, death screen, endings and classic PC windows keep their original appearance.

Critter art is in production and will arrive later as packs. The first pack is not published. No release date is promised.

**Dernière version : v1.4.** Fallout 2 n'est pas inclus : il te faut ta propre copie, achetée sur Steam, GOG ou Epic. C'est un projet de fans non officiel.

## Installation

### Android seulement

1. Télécharge et installe l'APK classique ou HD ci-dessus. Autorise ton navigateur ou ton gestionnaire de fichiers à installer des apps quand Android le demande.
2. Copie sur le téléphone le dossier de Fallout 2 ou une archive ZIP, 7z ou RAR. Il doit contenir `master.dat` et `critter.dat`.
3. Ouvre l'app, choisis le dossier ou l'archive et laisse le jeu s'importer. Dans l'édition HD, accepte ou reporte le téléchargement facultatif de l'art.

### PC Windows et téléphone Android

1. Télécharge et lance l'installateur Windows correspondant. Indique ta propre installation de Fallout 2 quand on te le demande.
2. L'installation peut transférer le jeu sur ton téléphone par USB ou débogage sans fil. Tu peux aussi le faire plus tard depuis le menu Démarrer.
3. Ouvre l'app **Wasteland** ou **Wasteland HD** sur le téléphone.

Consulte le [guide Windows en anglais](docs/INSTALL-WINDOWS.md), le [guide en français](docs/INSTALL-WINDOWS.fr.md) et le [dépannage](docs/TROUBLESHOOTING.fr.md) ([English](docs/TROUBLESHOOTING.md)).

### Linux

L'installation Linux est disponible avec `linux/install.sh` ; consulte le [guide en anglais](docs/INSTALL-LINUX.md) ou [en français](docs/INSTALL-LINUX.fr.md). L'installation sur un vrai téléphone depuis Linux n'a pas encore été testée.

### PNJ avec IA (optionnel)

Les PNJ avec IA sont optionnels et utilisent Ollama. Fallout 2 fonctionne sans IA et sans connexion Internet après l'installation.

## Contenu de l'art HD

Les packs HD remplacent les sols, murs, décors et objets du monde, les têtes parlantes, ainsi que les images d'inventaire, de butin, de troc, d'objet du HUD, de compétences, d'ascenseurs, de villes et les fonds de dialogue. Le Pip-Boy, le skilldex, les réglages (y compris l'apparence propre à l'interface tactile), le terrain de la carte du monde, l'écran de mort, les fins et les fenêtres classiques sur PC gardent leur apparence d'origine.

L'art des créatures est en production et arrivera plus tard sous forme de packs. Le premier pack n'est pas publié. Aucune date n'est annoncée.
