WASTELAND REBORN v1.4 — Fallout 2 sur Android et Windows
================================================================

CE QU'IL TE FAUT
- Windows 10 ou 11 (64 bits)
- Ta copie de Fallout 2 installee (Epic, Steam ou GOG). L'installation
  retrouve ton jeu et prend ses fichiers : rien du jeu n'est inclus ici.
- Optionnel : Ollama (https://ollama.com) pour les PNJ avec IA.
- Android 7.0 ou plus recent, arm64. APK classique : 5,2 Mo ; HD : 3,7 Mo.
  Apps : Wasteland et Wasteland HD. Une mise a jour APK garde les sauvegardes.
- Environ 2 Go libres pour le jeu ; garde au moins 3 Go avec l’art HD.
  Packs HD : monde 440 Mo (9 422 images), tetes 468 Mo (1 352 images) ;
  environ 910 Mo a telecharger et 2 Go decompresse avec le jeu.
- Fallout 2 n’est pas inclus : apporte ta copie. Projet de fans non officiel.

INSTALLER
1. Double-clique sur WastelandReborn-Setup.exe.
   Windows peut afficher « Windows a protege votre ordinateur » (le fichier
   n'est pas signe) : clique « Informations complementaires » puis
   « Executer quand meme ».
2. Suis l'installation. A la fin, une fenetre noire s'ouvre et pose des
   questions : ton jeu, l'IA, puis le telephone.
3. Joue avec l'icone « Wasteland Reborn » sur le bureau.

EDITION HD / INSTALLATION SILENCIEUSE
- WastelandRebornHD-Setup.exe s'installe a part, dans
  %LOCALAPPDATA%\WastelandRebornHD. Sauvegardes et reglages restent separes
  de l'edition classique.
- Lance n'importe lequel des deux installateurs avec /S pour une installation
  silencieuse : il cherche Fallout 2 (Epic, Steam ou GOG), copie le jeu si il
  le trouve et saute la configuration IA/telephone. Ensuite, menu Demarrer >
  « Wasteland - Configurer » pour la configurer normalement.
- L'installateur HD essaie les packs d'art HD publies une fois le jeu trouve.
  Sans connexion l'installation reussit quand meme : lis
  userdata\setup-install.log dans le dossier d'installation, puis relance
  « Wasteland - Configurer » quand les packs sont accessibles.
- Desinstallation : les fichiers de l'app, le registre et les raccourcis
  partent ; les sauvegardes (game\data\savegame) et les donnees IA restent.
- Tests hors ligne : python3 -m unittest discover -s windows/tests -v
- Sous Linux avec Wine/Xvfb, apres avoir construit les deux installateurs :
  bash windows/tests/test_wine_install.sh (il saute si gamedata/ est absent).

L'IA (si Ollama est installe)
- En dialogue, choisis « [Speak freely] » et ecris ce que tu veux au
  personnage (en anglais, c'est la langue du jeu).
- Le premier message peut prendre quelques secondes (chargement du modele).
- Ollama installe apres coup? Menu Demarrer > « Wasteland - Configurer ».

LE TELEPHONE
- L'installation installe adb (outil Android officiel de Google) toute seule.
- Sur le telephone : Options pour les developpeurs > Debogage sans fil ACTIVE,
  meme Wi-Fi que le PC. Un petit menu te laisse choisir le telephone (ou en
  associer un avec le code a 6 chiffres), ou passer.
- Plus tard : menu Demarrer > « Wasteland - Installer sur le telephone ».
- Apps : « Wasteland » (classique) et « Wasteland HD » ; elles coexistent.
- IA sur le telephone : le PC doit etre allume avec « Wasteland - Serveur IA
  (telephone) » ouvert. Dans le menu, choisis « Partout » pour que ca marche
  hors de la maison : l'installation installe Tailscale (VPN prive gratuit)
  sur le PC et le telephone. Connecte-toi avec le MEME compte sur les deux.

Les sauvegardes sont dans le dossier d'installation, game\data\savegame
(par defaut %LOCALAPPDATA%\WastelandReborn).
